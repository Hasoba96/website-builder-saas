# 23 — i18n / RTL / Localization

> **بادئة القواعد:** `IL-` · **الحالة:** إلزامي · **المالك:** Frontend
> **المرجع الأعلى:** [`../../en/00-PROJECT-RULES.md`](../../en/00-PROJECT-RULES.md) · **نسخة النظام الحاكمة:** [`../../en/systems/23-i18n-rtl.md`](../../en/systems/23-i18n-rtl.md) · هذه ترجمة عربية متزامنة.

## 0. لماذا هذا نظام مستقل

هذا منتج **عربي أولًا** ومتعدد اللغات. العربية ليست «لغة إضافية تُضاف لاحقًا» — هي **اللغة الأساسية لأغلب المستخدمين**، والـ RTL افتراض أساسي لا استثناء.

**القاعدة الحاكمة:** الـ RTL **قرار معماري من اليوم الأول**، لا مجموعة إصلاحات بعد الشكاوى.

> **لماذا:** إضافة RTL لاحقًا تعني مراجعة كل مكوّن، وكل ملف CSS، وكل أيقونة، وكل تخطيط في المنتج. التكلفة اليوم قريبة من الصفر؛ التكلفة بعد سنة هي إعادة بناء طبقة العرض كاملة.

---

## 1. مستويان مختلفان تمامًا

**`IL-001` (MUST):** التفريق الصارم بين:

| | لغة لوحة التحكم | لغة الموقع المنشور |
|---|---|---|
| من يحددها | المستخدم (صاحب الموقع) | إعداد الموقع نفسه |
| تؤثر على | واجهة لوحة التحكم والمحرّر | الموقع الذي يراه الزوار |
| مستقلة؟ | **نعم تمامًا** | **نعم تمامًا** |

**`IL-002` (MUST):** المستخدم يستطيع استعمال لوحة تحكم إنجليزية لبناء موقع عربي، والعكس. **ممنوع** ربط الاثنين.

> **لماذا:** مصمم أو وكالة قد يفضّل واجهة إنجليزية بينما يبني مواقع عربية لعملائه. الربط بينهما يجعل المنتج غير قابل للاستخدام لهذه الشريحة كاملة.

**`IL-003` (MUST):** المعاينة في المحرّر تعكس **لغة واتجاه الموقع**، لا لوحة التحكم (`VE-014`).

---

## 2. الاتجاه (Direction)

**`IL-010` (MUST):** الاتجاه من **primitives** لا patches (`FE-060`). القرار يُتخذ في طبقة التخطيط الأساسية.

**`IL-011` (MUST):** خصائص CSS **المنطقية حصريًا**:

| ❌ ممنوع | ✅ المطلوب |
|---|---|
| `margin-left` / `margin-right` | `margin-inline-start` / `margin-inline-end` |
| `padding-left` / `padding-right` | `padding-inline-start` / `padding-inline-end` |
| `left` / `right` | `inset-inline-start` / `inset-inline-end` |
| `text-align: left` | `text-align: start` |
| `border-left` | `border-inline-start` |
| `float: left` | `float: inline-start` |

**`IL-012` (MUST):** `dir` و `lang` مضبوطان صحيحًا على العنصر الجذر في كل من لوحة التحكم والموقع المنشور.

**`IL-013` (MUST):** الأيقونات:

| النوع | السلوك في RTL | أمثلة |
|---|---|---|
| **اتجاهية** | **تنعكس** | سهم، رجوع/تقدم، تراجع/إعادة، ترتيب |
| **غير اتجاهية** | **لا تنعكس** | بحث، إعدادات، مستخدم، حذف، بريد |
| **ذات معنى ثابت** | **لا تنعكس** | شعارات، علامات تجارية، ساعة، تشغيل |

> **لماذا التفصيل:** انعكاس أعمى لكل الأيقونات ينتج واجهة غريبة (ساعة معكوسة، شعار مقلوب). والعكس ينتج أسهمًا تشير للاتجاه الخطأ. القاعدة تحتاج تمييزًا لا آلية عمياء.

**`IL-014` (MUST):** الجداول والقوائم والتنقل تنعكس بالكامل، بما في ذلك ترتيب الأعمدة ومواضع الأزرار.

**`IL-015` (MUST):** المحتوى المختلط (نص عربي فيه كلمات إنجليزية أو أرقام أو روابط) يُعرَض صحيحًا. تُستخدم علامات عزل الاتجاه (`<bdi>` أو ما يكافئها) عند الحاجة.

> **لماذا:** بلا عزل، عنوان مثل «شركة ABC للتسويق» قد يُعرض بترتيب مشوَّه — وهو خطأ يظهر في مواقع عملاء حقيقيين.

## 3. الترجمة

**`IL-020` (MUST NOT):** **ممنوع** نص مكتوب مباشرة في مكوّن (`CORE-069`). كل نص معروض للمستخدم عبر طبقة الترجمة.

**`IL-021` (MUST):** مفاتيح الترجمة **هرمية ووصفية**:

```
editor.sections.hero.addButton
billing.plan.limitReached.title
errors.domain.notVerified
```

**`IL-022` (MUST NOT):** ممنوع بناء جملة بدمج أجزاء مترجَمة:

```ts
// ❌ خطأ: ترتيب الكلمات يختلف جذريًا بين اللغات
t('you.have') + ' ' + count + ' ' + t('websites')

// ✅ صحيح: الجملة كاملة مع متغيراتها
t('websites.count', { count })
```

**`IL-023` (MUST):** الجمع (pluralization) عبر آلية الترجمة. **العربية لها ست صيغ جمع** (صفر، واحد، اثنان، قليل، كثير، آخر) — لا يمكن التعامل معها بـ `if (n === 1)`.

**`IL-024` (MUST):** التواريخ والأرقام والعملات والمدد تُنسَّق بـ `Intl`، لا يدويًا.

**`IL-025` (MUST):** الأرقام في الواجهة العربية تتبع تفضيلًا موثَّقًا (عربية شرقية ٠١٢ أم غربية 012) — **متسقًا في المنتج كله**، ولا يُترك لاجتهاد كل شاشة.

**`IL-026` (MUST):** النص المترجَم قد يكون **أطول بـ 30–50%** من الإنجليزية. التخطيط يستوعب ذلك بلا كسر ولا قص.

**`IL-027` (MUST):** رسائل الخطأ مترجَمة عبر `error.code` (`API-022`)، لا بترجمة نص الخادم.

---

## 4. المواقع المنشورة

**`IL-030` (MUST):** كل موقع له `locale` و `direction` مخزَّنان في `websites`.

**`IL-031` (MUST):** الـ renderer يُخرج `lang` و `dir` صحيحين على `<html>` (`RP-040`).

**`IL-032` (MUST):** كل الـ section variants تعمل في RTL و LTR بلا استثناء، ومختبَرة في الاثنين (`CE-054`).

**`IL-033` (MUST):** الـ templates تحدد لغتها واتجاهها الافتراضيين (`CE-043`).

**`IL-034` (MUST):** محتوى الـ AI يُولَّد بلغة الموقع، ويُتحقق من ذلك.

**`IL-035` (MUST):** `hreflang` عند وجود أكثر من لغة لنفس المحتوى (`RP-044`).

---

## 5. الخطوط

**`IL-040` (MUST):** خطوط عربية تدعم المحارف كاملةً، بما فيها التشكيل والأرقام والعلامات.

**`IL-041` (MUST):** اختبار الخط مع: نص عربي طويل · نص مختلط · أرقام · رموز · علامات ترقيم.

**`IL-042` (MUST):** `font-display: swap` وتحميل مسبق للخطوط الحرِجة (`FE-072`).

**`IL-043` (MUST):** ارتفاع السطر (`line-height`) مناسب للعربية — **العربية تحتاج ارتفاعًا أكبر من اللاتينية** بسبب النقاط والمدود.

**`IL-044` (MUST):** الخطوط محمَّلة بمجموعات فرعية (subsets) لتقليل الحجم، مع التأكد من عدم فقد أي محرف مستخدَم.

## 6. الأنماط الممنوعة

| # | النمط | لماذا هو خطر |
|---|---|---|
| 1 | `margin-left` بدل المنطقي | تخطيط مكسور في RTL |
| 2 | ربط لغة لوحة التحكم بلغة الموقع | يُفقد شريحة كاملة من المستخدمين |
| 3 | نص مكتوب مباشرة في مكوّن | لا يمكن ترجمته |
| 4 | بناء جملة بدمج أجزاء | ترتيب كلمات خاطئ في العربية |
| 5 | `if (n === 1)` للجمع | العربية لها ست صيغ |
| 6 | تنسيق تاريخ يدويًا | خطأ في التقويم والتنسيق |
| 7 | انعكاس أعمى لكل الأيقونات | ساعات وشعارات مقلوبة |
| 8 | عدم عكس الأيقونات الاتجاهية | أسهم تشير للاتجاه الخطأ |
| 9 | تخطيط ثابت العرض | كسر مع النص الأطول |
| 10 | بلا عزل للنص المختلط | ترتيب مشوَّه في مواقع حقيقية |
| 11 | ارتفاع سطر لاتيني للعربية | نص مزدحم وصعب القراءة |
| 12 | خط بلا محارف عربية كاملة | مربعات فارغة في مواقع عملاء |
| 13 | الاختبار في LTR فقط | كل كسر RTL يكتشفه العميل |
| 14 | RTL كإصلاح لاحق | إعادة بناء طبقة العرض كاملة |

## 7. الاختبارات المطلوبة

**`IL-050` (MUST):** كل شاشة وكل variant مختبَران في **RTL و LTR** (`CE-072`, `FE-093`).

**`IL-051` (MUST):** اختبار النص الطويل: نص مترجَم أطول بـ 50% → لا كسر ولا قص.

**`IL-052` (MUST):** اختبار المحتوى المختلط: عربي + إنجليزي + أرقام + روابط → ترتيب صحيح.

**`IL-053` (MUST):** اختبار اكتمال الترجمة: **لا مفتاح ناقص** في أي لغة مدعومة — يفشل الـ build عند النقص.

**`IL-054` (MUST):** اختبار الجمع: كل صيغ الجمع العربية الست صحيحة.

**`IL-055` (MUST):** المعطيات تشمل عربيًا وإنجليزيًا دائمًا (`TS-027`).

**`IL-056` (MUST):** اختبار استقلال اللغتين: لوحة تحكم إنجليزية + موقع عربي → كلاهما صحيح.

## 8. Definition of Done — i18n & RTL

- [ ] لا نص مكتوب مباشرة — كل شيء عبر طبقة الترجمة.
- [ ] مفاتيح الترجمة هرمية ووصفية.
- [ ] لا جمل مبنية بالدمج.
- [ ] الجمع عبر آلية الترجمة (ست صيغ للعربية).
- [ ] التواريخ والأرقام والعملات بـ `Intl`.
- [ ] خصائص CSS منطقية حصريًا.
- [ ] `dir` و `lang` صحيحان في الجذر.
- [ ] الأيقونات الاتجاهية تنعكس، وغيرها لا.
- [ ] عزل صحيح للمحتوى المختلط.
- [ ] التخطيط يستوعب نصًا أطول بـ 50%.
- [ ] ارتفاع السطر مناسب للعربية.
- [ ] الخط يدعم كل المحارف المستخدَمة.
- [ ] لوحة التحكم ولغة الموقع مستقلتان.
- [ ] المعاينة تعكس اتجاه الموقع.
- [ ] مختبَر في RTL و LTR.
- [ ] لا مفاتيح ترجمة ناقصة.

---

## 9. ما يحتاج ADR

- إضافة لغة ثالثة للمنتج.
- دعم أكثر من لغة **لنفس الموقع** (محتوى متعدد اللغات).
- تغيير مكتبة الترجمة.
- تغيير تفضيل الأرقام العربية.
- إضافة لغة RTL أخرى بقواعد مختلفة.
